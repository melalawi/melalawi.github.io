# Post Style

## Rules
- Site changes MUST be subtle; font or size overhauls MUST NOT be made, and layout changes SHOULD be checked with screenshots.
- All site text MUST be lowercase outside code, including cartridge IDs, and pages MUST NOT carry subtitles; contact and resume MUST be dialogs linked from the sidebar footer.
- Posts MUST be technical, in plain first-person full sentences, with little opinion, and MUST NOT use framing or storytelling sentences, short dramatic fragments, parenthetical asides, terse semicolon notes, or AI-sounding padding.
- Each code block MUST be introduced by one plain sentence and MUST NOT be followed by a summary line; links MUST sit inside plain sentences.
- Bug posts MUST run gameplay conditions, media slot, code blocks captioned only with an italic "source" link, the shipped fix in plain words with the builds that got it, then a critique of whether the design was clean and where the bug lives.
- Posts MUST NOT include byte counts, smallest-possible trivia or cartridge codes, and MUST NOT quote the original developer directly; claims SHOULD be cited vaguely with footnote links at the bottom.
